# Greenroom mark

The Greenroom logo, chosen September 2026: a heavy one-stroke G whose right side is a person, with a
lime head and one arm raised. Everything here is exact vector geometry; start from the master.

| File | What it is |
|---|---|
| `greenroom-brand-guidelines.ai` | The brand guidelines, 13 pages (overview: `guidelines-overview.png`) |
| `greenroom-logo-final.ai` | The master: construction, four versions, the app icon at every size |
| `greenroom-logo-pieces.ai` | Every shape on its own layer, for experiments |
| `Greenroom.icns`, `Greenroom.iconset/` | The macOS app icon, every size (16 and 32 px use the small-size artwork) |
| `svg/` | The mark in colour, reversed, deep green only and white only; the app icon |
| `png/`, `png-pieces/`, `png-guidelines/` | Every artboard at 1:1 |
| `brainstorm/` | The exploration that led here |
| `source/` | The scripts that draw all of it (Python; `mcp.sh` needs `ILLUSTRATOR_MCP_TOKEN`) |

Colours: deep `#00401C`, lime `#78C000` (fill only, never text), white. See `DESIGN.md` for the rest.
Not yet installed in the app (`App/Assets.xcassets/AppIcon.appiconset`) or on the site (`docs/logo-mark.png`).
