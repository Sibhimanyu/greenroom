# A layout is one arrangement per display, not a one-display and a two-display version

A layout now holds a main-display arrangement and, optionally, a second-display arrangement. With only one display connected, Greenroom uses the main arrangement and ignores everything on the second display. There is no separate "one display" version and no One display / Two displays toggle; the editor shows the main canvas full width with a thin dashed strip that adds the second display, and once added both canvases sit side by side.

We chose this over keeping two versions (or deriving the laptop-only one automatically) because the owner found the toggle an unnecessary layer: what you see in the editor is what you get, and a missing display simply drops its part. The cost is a migration: layouts that had both versions keep their one-display arrangement as the main arrangement and their second-display pieces as the second arrangement; where the old two-display main arrangement differed, it is kept as a copy in the owner's own layouts so nothing is lost. A layout whose meeting sits only on the second display places no meeting window when that display is missing (the owner accepted this).
