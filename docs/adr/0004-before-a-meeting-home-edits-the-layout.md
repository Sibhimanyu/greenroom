# Before a meeting, Home edits the active layout; during one, changes are for this meeting

Supersedes the line in ADR 0001 that said "Home's live controls change only the running meeting, never the saved layout". With no meeting live, a change on Home (camera state, what's shared, the camera piece) changes the **saved** value in the active layout, and Home names that layout. While a meeting is live, the same controls make a change **for this meeting**, which ends with the meeting; every place that shows the setting shows the value in use, and Settings → Layouts says when a for-this-meeting change is in effect.

We chose this because, with ADR 0001's rule, picking a setting on Home before a meeting made a change for a meeting that did not exist yet, and Settings → Layouts then showed a different value with no sign why (owner, 2026-11-27: Home said *Only me*, Layouts said *Everyone & me*). Naming the layout on Home keeps what ADR 0001 wanted to protect, so a teaching set-up is never changed without the owner seeing which one. The alternative, keeping Home's choices temporary and marking them in Layouts, kept two values that could disagree before a meeting had even started.
