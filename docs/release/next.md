# Next release

## Easier setup

- Close setup from any page, including with Escape. Changes save as you go.
- Jump directly between steps using labeled progress dots, skip optional features together, and review a setup summary before finishing.
- Follow shorter instructions with detailed configuration tucked behind disclosures.

## Clearer Zoom connection setup

- Open the Zoom app builder directly, with instructions and credential fields grouped by app type.
- Copy each required hosting permission separately, matching Zoom’s one-at-a-time scope search.
- Run nine setup checks covering Meeting SDK credentials, hosting credentials and activation, all five hosting scopes, scheduled meeting lookup, and the hosting-token endpoint.
- View progress and results in a dedicated panel. Permission checks do not create or end a meeting.

## More compact Settings

- Keep illustrations while reducing card height, diagram padding, and repeated section gaps across all seven tabs.
- Use a compact Webcam preview with an enlarge option for fine adjustments.
- Show the camera angle readout beside switch timing and transition controls; pair related YouTube and Layout controls too.
- Choose a microphone from a native dropdown, retaining system-default input, refresh, and saved disconnected-device handling.
- Keep the Cues debug workbench available on demand rather than expanding it on every visit.
