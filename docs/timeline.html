02 · Release by release

What each morning taught the app

Filled dots are minor and patch releases; the lime dots are the ones that added a whole capability. Full notes for every version are on GitHub Releases.

Aug 6 · one day

Foundation

Three releases before dinner. The first was the ritual as a script; the second turned out to be most of the app.

0.1.0
Wed Aug 6 · 05:47
4,274 lines
New

The one-click morning: OBS virtual camera, Zoom meeting, tiled windows

  • Screen plus keyed webcam bubble as one virtual camera, driven by OBS in the background.
  • Start or join a Zoom meeting, then a configurable layout: any main app, the Zoom tile, a chat window.
  • Credentials travel as an exported settings file, so nobody else touches the Zoom Marketplace.
0.2.0
Wed Aug 6 · 15:15
5,989 lines · 39 commits
NewFixed

“Everything since 0.1.0, which turns out to be most of the app”

  • Scheduled meetings from the account, started as host; presenter webcam mode; people view on a second display.
  • Recordings to ~/Documents/Greenroom with an in-app player; system-wide shortcuts; live previews in Settings.
  • Fast Start: OBS stays warm between sessions, meeting creation and SDK auth run in parallel.
  • The cutout rendered the teacher at 1% opacity, in other words invisible. Fixed, along with the freezes that needed a force-quit.
0.2.1
Wed Aug 6 · 16:37
6,020 lines
Fixed

Quitting stops saying “Greenroom quit unexpectedly”

The Zoom SDK's engines crashed in their own destructors at process exit. Greenroom now shuts the SDK down itself, then leaves before the leftover teardown can run. It also comes back to the front when a session ends.

Aug 7 – 20 · two weeks

Self-updating, and hardened in class

The updater arrived, failed once, then made every later install automatic. The rest of the series is a list of things a real classroom did to the app.

0.3.0
Thu Aug 7 · 12:21
6,041 lines
Never launched

The build that could not start

A build step that embeds the Zoom SDK deleted the Sparkle framework right after Xcode put it in the bundle. The app crashed on open on every Mac; downloads were pulled. The lasting result: the release script now resolves every linked library against the bundle and launches the exact shipped bytes before anything is published.

0.3.1
Sat Aug 9 · 16:55
6,041 lines
New

The last version anyone installs by hand

Sparkle auto-updates, EdDSA-signed, with Install and Relaunch and a Check for Updates… item in the app and menu bar. From here on, releases arrive on their own.

0.3.2
Sun Aug 10 · 04:13
6,108 lines
Fixed

Browsers open their own window again; OBS stops crashing on quit

Picking a Chromium browser had tiled the teacher's entire existing tab pile. A fresh window per session fixed it. A system-audio capture queue Greenroom never used was what made OBS crash on the way out.

0.3.3
Sun Aug 17 · 06:08
6,246 lines
New

Meeting presets, and the “Is it safe?” page

  • Presets save regular meetings (name, ID, passcode) and travel in the settings export.
  • The transparency page: not AI, not watching the screen, not a keylogger, with a capability inventory for IT.
  • Honest about credential storage: plain text in local preferences, never the Keychain, never sent anywhere but Zoom.
0.3.4
Mon Aug 18 · 07:22
6,781 lines · 11 commits
FixedNew

No more windows bursting open full-screen

  • Zoom's persisted auto-full-screen setting is cleared every session; window placement is deterministic; a standing guard keeps stray meeting windows off the shared screen.
  • Quitting finalizes any recording, ends the hosted meeting and winds OBS down. Self-view is no longer mirrored.
  • ⌥⌘Z quick-hide for the speaker tile; pick which display the participant view opens on; Hide Self View becomes a preference.
0.3.5
Mon Aug 18 · 09:03
6,947 lines
Fixed

Dual display, done right

The main display's corner tile is the clean speaker view; the extended display gets the participant grid with Zoom's controls. They had been swapped, with the grid never appearing. The OBS scene also rebuilds itself from nothing, and a Mac with no webcam still starts a screen-only session.

0.3.6
Mon Aug 18 · 10:34
7,205 lines
New

Layout by direct manipulation

  • The fixed ½ / ⅔ / ¾ presets are gone: drag the handle between the panes, and between Zoom and Chat. Changes re-tile the live windows moments after you let go.
  • End Session asks first. Recordings become fragmented MP4, so a crash loses seconds, not the file.
0.3.7
Tue Aug 19 · 01:47
7,385 lines · 19 commits
Fixed

A design-system pass, and the grid finally stays put

Brand green everywhere, for real: a user's own accent colour had been overriding the app's. The participant grid stops fleeing to the main display when clicked; closing the main window and getting it back always works; quitting feels instant.

0.3.8
Wed Aug 20 · 06:30
8,018 lines
Fixed

OBS quits quietly; windows go to the right display

Four separate causes of the “OBS quit unexpectedly” dialog, tracked down and closed. Windows land on the main display rather than whichever had keyboard focus. The Recordings window shows how much disk is left and warns before a class that might not fit.

Aug 24 · one Sunday

The teaching surface

The custom meeting UI grows from an experiment into the app's own console, and the recorder learns to clip the past. The code doubles in a day.

0.4.0
Sun Aug 24 · 04:23
16,588 lines · 52 commits
New

Clips after the fact, and a participants panel built for teaching

  • ⌥⌘1, 2 or 5 saves the last one, two or five minutes, recording or not: a rolling buffer held in memory, written only when you press the key.
  • Participants panel: the live speaker held large, every student in a grid, hands up in the order raised, mute / spotlight / admit / rename one click away.
  • Chat rebuilt: images and files, replies, day dividers, an unread marker. A meeting a crash left live is ended before the new one starts.
0.4.1
Sun Aug 24 · 04:41
16,599 lines
Fixed

The meeting tile is identified first, always

On a single display with Zoom's own UI, the tile could be mistaken for the participant gallery and pushed behind the workspace, which also left ⌥⌘Z reporting “no speaker tile” all session.

0.5.0
Sun Aug 24 · 07:02
16,802 lines
NewFixed

The live speaker window works

  • Opens by itself with three people in class, switching as the conversation moves; ⌥⌘Z hides and shows it, Snap Windows Back puts it home.
  • Participant video is stable: every stream sized against Zoom's subscription budget, ending the “one view works, the other goes black” seesaw.
  • Photos a student sends preview in chat; avatars show proper initials.
Sep 3 · one morning

Sound, and a browser of its own

A quiet bug that had shadowed every recording, then the first piece of the workspace Greenroom draws itself.

0.5.1
Wed Sep 3 · 11:24
16,821 lines
Fixed

Recordings have sound

Every recording and clip so far carried a silent audio track: the screen capture had its audio off and the webcam feed was video only, so nothing in the scene was listening to the microphone. A dedicated mic input now follows the system input device and is un-muted on every start.

0.6.0
Wed Sep 3 · 12:49
18,781 lines
New

Greenroom Browser

  • A new choice at the top of the Main app list: a WebKit window Greenroom owns, so it tiles itself with no Accessibility or Automation permission and Snap Windows Back is instant.
  • Tabs in the title bar, an address bar that searches and suggests, ⌘F find, ⌘Y history kept on the Mac, ⌘-click background tabs, ⌘⇧T, ⌘P.
  • Start brings yesterday's tabs back, with the website from Settings on top. Switches for search suggestions and closing the window with the session.

Chrome and every other installed browser stay in the list for the days an extension is needed.
